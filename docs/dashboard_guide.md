# دليل تشغيل Dashboard

## التشغيل المحلي

افتح PowerShell داخل مجلد `FYP_II` ثم نفّذ:

```powershell
streamlit run app\streamlit_app.py
```

سيفتح Streamlit رابطاً محلياً، غالباً `http://localhost:8501`.

## الصفحات المتاحة

1. الملخص التنفيذي.
2. مقارنة مجموعات A/B.
3. Retention & Cohorts.
4. قنوات الاكتساب.
5. الإيراد وصيغ الإعلانات.
6. الاختبارات الإحصائية.
7. المنهجية وجودة البيانات.

## حماية البيانات

التطبيق يقرأ حصراً من `data/marts/*.parquet`. لا يقرأ ملفات `data/raw` أو معاملات المستخدمين، ولا تحتوي الملفات المعروضة على `user_id`.

## اختبار التشغيل

```powershell
python tests\run_dashboard_checks.py
```

الاختبار يفتح الصفحات السبع باستخدام أداة الاختبار الرسمية المدمجة في Streamlit ويتأكد من عدم ظهور استثناءات. قد يظهر تحذير `ScriptRunContext` عند التشغيل في وضع الاختبار المجرد؛ لا يؤثر في التطبيق الفعلي.
