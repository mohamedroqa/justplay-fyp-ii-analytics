# ملخص طبقة Data Marts

تاريخ البناء والتحقق: **13 أكتوبر 2026**

## الهدف

تحويل طبقة البيانات المعالجة الكاملة إلى ملفات صغيرة ومجمعة يمكن للداشبورد وExcel قراءتها بسرعة، دون نشر معاملات فردية أو معرفات مستخدمين.

## الملفات الناتجة

| الملف | عدد الصفوف | الاستخدام |
|---|---:|---|
| `overall_kpis.parquet` | 1 | المؤشرات العامة للمشروع |
| `variation_summary.parquet` | 5 | مقارنة مجموعات تجربة A/B |
| `channel_summary.parquet` | 19 | تحليل قنوات الاكتساب |
| `country_summary.parquet` | 2 | مقارنة US وCA |
| `retention_cohorts.parquet` | 45 | Retention حسب أسبوع التثبيت والـVariation |
| `ad_format_summary.parquet` | 4 | أداء صيغ الإعلانات |
| `revenue_type_summary.parquet` | 3 | توزيع مصادر الإيراد |

## التحقق

نجحت ثمانية فحوصات آلية تشمل مطابقة الأعداد والمجاميع المالية بين جميع الجداول، صحة حقول Retention، ومراجعة الخصوصية. لا يحتوي أي Data Mart على الحقل `user_id`.

أداة البناء: `src/analytics/build_data_marts.py`  
أداة التحقق: `tests/run_data_mart_checks.py`  
تقرير التشغيل: `logs/data_marts_build_report.json`

## ملاحظة تفسيرية

الفروقات الظاهرة بين الـVariations في المتوسطات وصفية فقط في هذه المرحلة. لا يجوز وصف أي Variation بأنه الأفضل إحصائياً قبل تنفيذ اختبارات الدلالة، فواصل الثقة، أحجام الأثر، وتصحيح المقارنات المتعددة.
